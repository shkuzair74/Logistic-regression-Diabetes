# Logistic-regression-Diabetes
Predicts diabetes risk from health measurements (glucose, BMI, insulin, age, etc.) using Logistic Regression on the Pima Indians dataset. Includes EDA, IQR outlier treatment, feature scaling and a Streamlit app for real-time predictions. Achieves 75% accuracy and 0.81 ROC-AUC. Built with Python, Pandas and Scikit-learn.
